**The cuda-oxide Book**

The cuda-oxide Book is an experimental Rust-to-CUDA compiler that enables writing (SIMT) GPU kernels in safe, idiomatic Rust. It compiles standard Rust code directly to PTX, eliminating the need for DSLs or foreign language bindings. The project assumes familiarity with Rust, including ownership, traits, and generics.

A quick start example demonstrates the use of cuda-oxide to launch a kernel:
```rust
use cuda_device::{kernel, launch_bounds, launch_contract, thread, DisjointSlice};
use cuda_host::cuda_module;
use cuda_core::{CudaContext, DeviceBuffer, LaunchConfig1D};

#[cuda_module]
mod kernels {
    use super::*;

    #[kernel]
    #[launch_bounds(256)]
    #[launch_contract(domain = 1, block = (256, 1, 1))]
    pub fn vecadd(a: &[f32], b: &[f32], mut c: DisjointSlice<f32>) {
        let idx = thread::index_1d();
        let i = idx.get();
        if let Some(c_elem) = c.get_mut(idx) {
            *c_elem = a[i] + b[i];
        }
    }
}

Fn main() {
    let ctx = CudaContext::new(0).unwrap();
    let stream = ctx.default_stream();
    let module = unsafe { kernels::load(&ctx).unwrap() };
    let a = DeviceBuffer::from_host(&stream, &[1.0, 2.0, 3.0, 4.0]);
    let b = DeviceBuffer::from_host(&stream, &[5.0, 6.0, 7.0, 8.0]);
    let mut c = DeviceBuffer::from_host(&stream, &[0.0, 0.0, 0.0, 0.0]);
    let launch_config = LaunchConfig1D::new(256, 1, 1);
    unsafe {
        kernels::vecadd<<<launch_config, 256, 0, stream>>>(
            a.as_ptr(),
            b.as_ptr(),
            c.as_mut_ptr(),
        );
    }
    stream.synchronize().unwrap();
    println!("{:?}", c.to_host(&stream));
}
```
This example showcases the cuda-oxide compiler's ability to generate efficient CUDA code from Rust.
