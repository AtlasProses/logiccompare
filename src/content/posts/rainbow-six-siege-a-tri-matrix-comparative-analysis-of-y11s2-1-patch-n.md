### Telemetry Calculations: Frame-Time Spikes Elimination
To eliminate frame-time spikes, we can use the following formula:

Frame-Time Spike Elimination (FTSE) = (Average Frame Time x Number of Frames) / (1 - (Packet Buffer Jitter x Input Latency))

Where:

* Average Frame Time: The average time it takes to render a single frame
* Number of Frames: The number of frames rendered per second
* Packet Buffer Jitter: The average time difference between packet arrival and processing
* Input Latency: The average time delay between user input and response

By minimizing packet buffer jitter and input latency, we can reduce frame-time spikes and improve overall performance.
