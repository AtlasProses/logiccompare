#### **2. Bybit’s Perpetual Settlement Logic (Smart Contract Pseudocode)**
Bybit’s perpetual contracts for **Moonshot AI** and **Unitree** rely on **oracle-driven price feeds** and **automated liquidation mechanics**. Below is a **simplified smart contract logic** (EVM-style):

```solidity
contract PreIPOPerpetual {
    address public oracle;
    uint256 public lastPrice;
    uint256 public leverageRatio; // e.g., 10x for Moonshot AI

    event PriceUpdate(uint256 newPrice);
    event Liquidation(address trader, uint256 collateral);

    function updatePrice(uint256 newPrice) external {
        require(msg.sender == oracle, "Only oracle can update price");
        lastPrice = newPrice;
        emit PriceUpdate(newPrice);
    }

    function settleTrades() external {
        for (uint i = 0; i < traders.length; i++) {
            Trader storage trader = traders[i];
            uint256 pnl = (trader.position * lastPrice) - (trader.entryPrice * trader.position);

            if (trader.collateral < (trader.position * leverageRatio * lastPrice)) {
                // Liquidation trigger
                trader.collateral = 0;
                emit Liquidation(trader.address, trader.collateral);
            } else {
                trader.collateral += pnl;
            }
        }
    }
}
```

**Key Insight**: Bybit’s system **decouples ownership from exposure**—traders gain **price sensitivity without holding shares**, but **liquidity risk remains tied to oracle reliability** (e.g., Unitree’s STAR Market approval as a "hard stop" event).
